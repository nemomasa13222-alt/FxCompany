# 引き継ぎ書 フォーマット定義

ファイル名: `YYYY-MM-DD.md`
作成タイミング: 毎セッション終了時
作成者: 孫さん（AI CEO）

---

## フォーマット

```markdown
# 引き継ぎ書  YYYY-MM-DD

## 今日やったこと
- 箇条書きで簡潔に
- 完了したものは ✅、未完了は ⚠️

## 稼働中システム（毎日確認）

| システム | 状態 | 確認場所 |
|---------|------|---------|
| 株デモ GitHub Actions | 稼働中 / 停止 | .github/workflows/demo_automation.yml |
| FX MT4 EA | 稼働中 / 停止 | MT4 エキスパートタブ |
| FX push_trades タスク | 稼働中 / 停止 | Windowsタスクスケジューラ |

## 重要な数字（最新）

### 株デモ
- 累積損益: X万円 / 勝率: X% / PF: X.XX / 件数: X件
- 最終更新: YYYY-MM-DD

### FX MT4 デモ
- 累積損益: X円 / 勝率: X% / 件数: X件
- 残高: X円（初期100万円）
- 最終更新: YYYY-MM-DD

## 未解決・継続タスク
- [ ] タスク内容（優先度: 高/中/低）
- [ ] ...

## 明日やること（提案）
1. 優先度順に記載

## 注意事項・引き継ぎメモ
- 次の孫さんが知っておくべきこと
- バグ・懸念点・判断保留事項

## 意思決定ログ
- 今日した重要な決定とその理由
```

---

## 運用ルール

1. **毎セッション終了前**に孫さんが作成する
2. 前日の引き継ぎ書を読んでからセッションを開始する
3. 数字は実績値を書く（推測・見込み不可）
4. 「明日やること」は3件以内に絞る
5. ファイル名は `YYYY-MM-DD.md`（当日の日付）
